# Rosh: apresentação do sistema

Apresentação do Rosh, o sistema de pedidos para a tabacaria do lounge.

- **Início** (`index.html`): uma noite no lounge com o Rosh.
- **Tour guiado** (`tour.html`): as telas do sistema, passo a passo.
- **Explorar as telas** (`previa.html`): a prévia para usar à vontade.
- **Em 2 minutos** (`animacao.html`): a visão geral animada.
- **Detalhes** (`especificacao.html`): tudo o que o sistema faz.

Os nomes, as mesas e os valores que aparecem nas telas são exemplos.
